# Healthcare Analytics Project
This project focuses on analyzing healthcare data using Python and Jupyter Notebook to identify patterns, trends, and insights related to patient demographics, medical conditions, hospital admissions, insurance coverage, and healthcare costs.
The project includes data cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization using various charts and graphs. The findings help improve understanding of healthcare utilization patterns and support data-driven decision-making.
For complete project details, methodology, visualizations, insights, recommendations, and future scope, please refer to the attached Main Project Documentation.pdf.
